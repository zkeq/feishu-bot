# 💰 财务管家 (Finance Manager Bot)

一个功能全面、UI美观的飞书财务管理机器人，支持自然语言交互、智能账户匹配、收据图片识别等功能。

## ✨ 核心特性

### 1. 🏠 智能控制面板
- 输入 `/start` 打开财务控制面板
- 实时显示财务概览（总资产、总负债、净资产）
- 本月预算执行情况一目了然
- 账户和债务列表完整展示
- 一键访问所有功能

### 2. 📊 财务状态管理
- 支持多种账户类型（存款、债务、分期、投资）
- 自动计算总资产、总负债、净资产
- 实时追踪财务健康度
- 智能账户余额更新

### 3. 💰 预算规划
- 基于"大额合并原则"的预算管理
- 区分固定支出和可变支出
- 实时追踪预算执行情况
- 自动计算预算剩余和执行率

### 4. 💸 消费记录
- **文字描述**：自然语言记录消费
- **图片识别**：发送收据照片自动识别
- **智能分类**：根据预算自动分类
- **智能匹配**：AI自动匹配支付方式到账户
- **表联动**：自动更新账户余额和预算执行

### 5. 💳 债务管理
- 区分日常负债（花呗/信用卡）和分期债务
- 自动追踪分期还款进度
- 只有明确说"分期"的才进入债务分期表
- 日常消费自动更新账户余额

### 6. 🤖 AI 智能助手
- 自然语言理解（"小荷包存款 X w，花呗欠 X k"）
- 智能消费建议
- 主动查询数据库，给出准确答案
- 支持多种金额表达（2k=2000元，1.5w=15000元）

## 🗄️ 数据库设计

### 表1: 财务账户表 (finance_accounts)
| 字段 | 类型 | 说明 |
|------|------|------|
| 用户ID | 人员 | 关联用户 |
| 账户名称 | 文本 | 如"小荷包"、"花呗" |
| 账户类型 | 单选 | 存款/债务/分期/投资 |
| 当前余额 | 数字 | 当前金额（元），负数表示负债 |
| 更新时间 | 日期 | 最后更新时间 |
| 状态 | 单选 | 活跃/已关闭 |
| 备注 | 文本 | 额外说明 |

### 表2: 预算计划表 (budget_plans)
| 字段 | 类型 | 说明 |
|------|------|------|
| 用户ID | 人员 | 关联用户 |
| 月份 | 文本 | YYYY-MM格式 |
| 类型 | 单选 | 收入/固定支出/可变支出/应急 |
| 类别名称 | 文本 | 具体类别 |
| 预算金额 | 数字 | 计划金额（元） |
| 实际金额 | 数字 | 实际金额（元） |
| 创建时间 | 日期 | 创建时间 |
| 备注 | 文本 | 额外说明 |

### 表3: 消费记录表 (expense_records)
| 字段 | 类型 | 说明 |
|------|------|------|
| 用户ID | 人员 | 关联用户 |
| 消费时间 | 日期 | 消费日期时间（Unix时间戳） |
| 金额 | 数字 | 消费金额（元） |
| 类别 | 单选 | 餐饮/交通/购物/娱乐/其他 |
| 支付方式 | 单选 | 现金/微信/支付宝/信用卡/花呗 |
| 商家名称 | 文本 | 商家或描述 |
| 预算类型 | 单选 | 固定支出/可变支出 |
| 收据图片 | 附件 | 消费截图（自动上传） |
| 备注 | 文本 | 额外说明 |
| 创建时间 | 日期 | 记录创建时间 |

### 表4: 债务分期表 (debt_installments)
| 字段 | 类型 | 说明 |
|------|------|------|
| 用户ID | 人员 | 关联用户 |
| 债务类型 | 单选 | 分期付款/借款 |
| 债务名称 | 文本 | 描述（如"iPhone 15分期"） |
| 总金额 | 数字 | 总欠款（元） |
| 已还金额 | 多行文本 | 已还金额（元） |
| 总期数 | 数字 | 分期总数 |
| 当前期数 | 数字 | 当前第几期 |
| 每期金额 | 数字 | 每期还款（元） |
| 下次还款日 | 日期 | 下次还款时间（可选） |
| 状态 | 单选 | 进行中/已结清 |
| 备注 | 文本 | 额外说明 |

**注意**：花呗和信用卡的日常消费不进入此表，只在财务账户表中体现为负债账户。

## 🔧 配置说明

### 1. 创建多维表格
在飞书中创建4个多维表格，按照上述字段设计配置。

### 2. 更新配置文件
复制 `config.example.yaml` 为 `config.yaml`，填入实际的 `app_token` 和 `table_id`：

```yaml
bitable:
  enabled: true
  app_token: "你的app_token"  # 替换为实际值

  accounts_table:
    table_id: "你的table_id"  # 替换为实际值
    fields:
      user_id: "用户ID"
      account_name: "账户名称"
      # ... 其他字段
```

### 3. 配置飞书应用
在 `config/bots.yaml` 中配置飞书应用信息：

```yaml
bots:
  - name: finance_manager
    module: bots.finance_manager.bot
    class: FinanceManagerBot
    feishu:
      app_id: "你的app_id"
      app_secret: "你的app_secret"
```

### 4. 启动机器人
```bash
python main.py
```

## 🔄 表格联动机制

当用户记录消费时，系统自动：
1. **创建消费记录** → `expense_records` 表
2. **智能匹配账户** → AI匹配支付方式到账户名称
3. **更新账户余额** → `finance_accounts` 表
4. **更新预算执行** → `budget_plans` 表
5. **上传收据图片** → 飞书文件系统（如果有图片）

## 🚀 核心技术实现

### 1. 智能账户匹配
使用AI自动匹配支付方式到账户名称，无需硬编码：
```python
# 用户说"用花呗付的"
# AI自动匹配到账户表中的"花呗"账户
# 自动更新该账户余额
```

### 2. 收据图片处理
- 自动上传图片到飞书文件系统
- 获取 file_token 并保存到附件字段
- 支持图片识别（AI自动提取商家、金额等信息）

### 3. 异步卡片交互
- 立即返回响应，避免超时
- 后台线程处理实际操作
- 完成后发送通知消息

### 4. 字段统一提取
- 使用 `_extract_text_value` 统一处理飞书结构化字段
- 自动提取 `[{'text': 'value', 'type': 'text'}]` 格式

### 5. 时间格式转换
- AI返回的时间字符串自动转换为Unix时间戳
- 支持多种时间格式
