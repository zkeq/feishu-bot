# 💰 财务管家 (Finance Manager Bot)

一个功能全面、UI美观的飞书财务管理机器人。

## ✨ 核心特性

### 1. 🏠 控制面板首页
- 输入 `/start` 即可打开财务控制面板
- 美观的卡片UI展示财务概览
- 一键访问所有功能

### 2. 📊 财务状态管理
- 支持多种账户类型（存款、债务、分期、投资）
- 自动计算总资产、总负债、净资产
- 实时追踪财务健康度

### 3. 💰 预算规划
- 基于"大额合并原则"的预算管理
- 区分固定支出和可变支出
- 实时追踪预算执行情况

### 4. 💸 消费记录
- 智能识别消费类别
- 支持收据截图识别
- 自动更新预算执行

### 5. 💳 债务管理
- 追踪花呗、信用卡、分期付款
- 自动计算还款进度
- 提醒还款日期

### 6. 🤖 AI 智能助手
- 自然语言理解（"小荷包存款 X w，花呗欠 X k"）
- 智能消费建议
- 上下文感知（查询现有财务数据）

## 🎯 功能按钮

### 📝 编辑计划

### 💬 财务询问
向AI询问财务相关问题，获取智能建议

### 💸 记录消费
快速记录消费，自动更新预算

查看和管理所有债务

## 🗄️ 数据库设计

### 表1: 财务账户表 (finance_accounts)
| 字段 | 类型 | 说明 |
|------|------|------|
| 用户ID | 人员 | 关联用户 |
| 账户名称 | 文本 | 如"小荷包" |
| 账户类型 | 单选 | 存款/债务/分期/投资 |
| 当前余额 | 数字 | 当前金额（元） |
| 更新时间 | 日期 | 最后更新时间 |
| 状态 | 单选 | 活跃/已关闭 |
| 备注 | 文本 | 额外说明 |

### 表2: 预算计划表 (budget_plans)
| 字段 | 类型 | 说明 |
|------|------|------|
| 用户ID | 人员 | 关联用户 |
| 月份 | 文本 | YYYY-MM格式 |
| 类型 | 单选 | 收入/固定支出/可变支出/应急 |
| 类别名称 | 文本 | 具体类别 |
| 预算金额 | 数字 | 计划金额（元） |
| 实际金额 | 数字 | 实际金额（元） |
| 创建时间 | 日期 | 创建时间 |
| 备注 | 文本 | 额外说明 |

### 表3: 消费记录表 (expense_records)
| 字段 | 类型 | 说明 |
|------|------|------|
| 用户ID | 人员 | 关联用户 |
| 消费时间 | 日期 | 消费日期时间 |
| 金额 | 数字 | 消费金额（元） |
| 类别 | 单选 | 餐饮/交通/购物/娱乐/其他 |
| 支付方式 | 单选 | 现金/微信/支付宝/信用卡/花呗 |
| 商家名称 | 文本 | 商家或描述 |
| 预算类型 | 单选 | 固定支出/可变支出 |
| 收据图片 | 附件 | 消费截图 |
| 备注 | 文本 | 额外说明 |
| 创建时间 | 日期 | 记录创建时间 |

### 表4: 债务分期表 (debt_installments)
| 字段 | 类型 | 说明 |
|------|------|------|
| 用户ID | 人员 | 关联用户 |
| 债务类型 | 单选 | 花呗/信用卡/分期付款/借款 |
| 债务名称 | 文本 | 描述 |
| 总金额 | 数字 | 总欠款（元） |
| 已还金额 | 数字 | 已还金额（元） |
| 总期数 | 数字 | 分期总数 |
| 当前期数 | 数字 | 当前第几期 |
| 每期金额 | 数字 | 每期还款（元） |
| 下次还款日 | 日期 | 下次还款时间 |
| 状态 | 单选 | 还款中/已结清 |
| 备注 | 文本 | 额外说明 |

## 🔧 配置说明

### 1. 创建多维表格
在飞书中创建4个多维表格，按照上述字段设计配置。

### 2. 更新配置文件
编辑 `config.yaml`，填入实际的 `app_token` 和 `table_id`：

```yaml
bitable:
  enabled: true
  app_token: "你的app_token"  # 替换为实际值

  accounts_table:
    table_id: "你的table_id"  # 替换为实际值
    fields:
      user_id: "用户ID"
      account_name: "账户名称"
      # ... 其他字段
```

### 3. 启动机器人
```bash
python main.py
```

## 💡 使用示例

### 示例1: 更新财务状态
```
用户: 小荷包存款X万，花呗欠Y千，信用卡欠Z千，还有N期M千正在还第一期

Bot: ✅ 财务状态已更新

📊 账户明细
• 小荷包: X元 (存款)
• 花呗: -Y元 (债务)
• 信用卡: -Z元 (债务)
• 分期付款: -M元 (N期，第1期，每期XXX元)

💰 财务汇总
• 总资产: X元
• 总负债: Y元
• 净资产: Z元
```

### 示例2: 创建预算
```
用户: 帮我规划预算，收入工资X元，兼职Y元，固定支出房租Z元，可变支出W元

Bot: ✅ 预算规划已生成

📊 当月预算
• 总收入: X元
• 总支出: Y元
• 可支配: Z元
```

### 示例3: 消费建议
```
用户: 我想买一个X元的商品

Bot: ⚠️ 消费建议

想购买: 商品 (X元)

预算分析:
• 可变支出预算: Y元
• 已消费: Z元
• 剩余: W元
• 购买后: V元 ⚠️

建议: [根据实际情况给出建议]

替代方案:
1. 等到下个月再购买
2. 考虑更便宜的替代品
```

## 🎨 UI 设计特点

### 1. 现代化卡片
- 使用飞书卡片的 column_set 实现多列布局
- 灰色背景突出重要数据
- 清晰的分隔线和层次结构

### 2. 丰富的 Emoji
- 💰 资产
- 💳 债务
- 📊 数据
- ✅ 成功
- ⚠️ 警告
- ❌ 错误

### 3. 交互式按钮
- 主要操作使用 primary 样式
- 危险操作使用 danger 样式
- 普通操作使用 default 样式

## 🔄 表格联动机制

当用户记录消费时，系统自动：
1. 创建消费记录 → `expense_records` 表
2. 更新账户余额 → `finance_accounts` 表
3. 更新预算执行 → `budget_plans` 表
4. 如果使用债务支付，更新 → `debt_installments` 表
